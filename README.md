# 📊 Daterium AI
**Discover. Decode. Dominate.**

Daterium is an intelligent economic companion designed for educators and students to navigate current affairs and economic data.

### ✨ Key Features
- **Daily Economic Digest:** Summarized news from IMF, World Bank, and local markets.
- **Beginner's Lab:** Complex economic formulas explained simply.
- **Data Analyst Toolbox:** Instant visualization for Excel/CSV uploads.
